## 📋 0. 概要

マジョリンスイーツのブランドサイトに対し、**春シーズン向けアップデート** を一括実施する。
主な変更は以下の6カテゴリ:

1. **トップヒーロー**: 画像差し替え(2枚スライダー化)+ キャプション変更
2. **ようこそ画面(執事セレクト)**: 文言変更 + カラー変更(黄→黒系)
3. **パウンドケーキ販売箇所**: 暫定イメージ画像に差し替え
4. **占い機能**: 既存「バブル→写真消失」を「バブル→手紙ポップアップでマジョリンのメッセージ表示」に変更 + メッセージ50種→10種
5. **STORYセクション**: 見出し・本文の文言刷新
6. **「魔法で作ったもの〜」セクション**: 画像を春用に差し替え

**全体方針**: 現行の黄色アクセントを排し、**ロゴカラーのピンク + モノトーン** で大人っぽい統一感を出す。

### A. トップヒーローセクション

#### A-1. 画像のスライダー化

**現状**: 静止画1枚(コテージ前の女性、ロングコート姿)
**変更後**: 春用画像2枚をクロスフェードで切り替え

**スライダー仕様**:
```yaml
画像: 
  - public/images/spring2026/hero_spring_01.png
  - public/images/spring2026/hero_spring_02.png
切り替え方式: クロスフェード(opacity transition)
切り替え間隔: 5秒
自動再生: ON
ループ: ON
インジケーター: 下部に小さくドット表示(任意)
モバイル: スワイプ操作対応
```

**実装ヒント**:
- 既存ヒーローコンポーネントを拡張(`HeroSection.tsx` 等)
- Reactフック(`useEffect` + `setInterval`)で実装、または `swiper` / `embla-carousel` 等のライブラリ使用可
- キャプションは画像レイヤーと **独立** させて、スライド切り替えとは別に常時表示

#### A-2. キャプション文言変更

**配置・フォント・レイアウト**: 現行と同一を維持(変更はテキスト内容のみ)

**新コピー**:

- **「MAJORIN SWEETS」ロゴ部分**: **現行色のまま据え置き**(変更しない)
- **キャプション本文**: **白文字 + 黒フチ(text-stroke)**

```css
.hero-caption-body {
  color: #FFFFFF;
  -webkit-text-stroke: 1px #000000;
  text-stroke: 1px #000000;
  text-shadow: 0 0 2px rgba(0, 0, 0, 0.6);
```

> フチの太さは1〜1.5pxを基本、視認性を見て調整。

### D. 占い機能 ★重要変更★

#### D-1. インタラクション挙動の変更

**現状(既存実装)**:
- 画面に **マジョリンの写真がバブル(球体)として空中に浮かんでいる** エフェクトがある
- ユーザーがバブルをクリック/タップで弾くと、マジョリンの写真が消える

**変更後(新仕様)**:
- バブルを弾く動作はそのまま継承
- バブルを弾いた **直後** に、画面に **手紙(レター)のポップアップが浮き上がるアニメーション** で出現
- ポップアップ内には **マジョリンからのメッセージ(名言)** が1件表示される
- メッセージは **10種類のメッセージプールからランダム選出**

**実装ヒント**:
```yaml
ポップアップ仕様:
  形式: 中央モーダル or 中央付近に浮き上がる手紙風カード
  アニメーション: 
    - 出現: フェードイン + 軽くスケール(0.8 → 1.0) + 軽く上方向に浮上(translateY: 20px → 0)
    - 消滅: フェードアウト + 上方向にフェードオフ
  デザイン: 
    - 手紙風のレイアウト(古紙テクスチャ背景、罫線、手書き風フォント推奨)
    - マジョリンらしい世界観を維持(深いピンク・モノトーン基調)
  閉じる動作: 
    - 外側クリック / ✕ボタン / ESCキー / 数秒で自動消滅(任意)
  メッセージ選定: 
    - 10件の配列からランダム抽選
    - 同じセッションで重複しない工夫があると尚良(任意)
```
